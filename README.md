# Protein Visualizer with Plotly

A python script which enables you to visualize the element name, residue number, residue name, b_factor and atom name of any protein. Proteins must use the **PDB** format, which you can download from the AlphaFold website.

How to use:
1. Download any protein with the **PBD** file format (likely from AlphaFold)
2. Open and run `proteinvisualizer.py` in your IDE
3. From your files, copy the path of the file and paste it into the script.
4. Select your preferred options
